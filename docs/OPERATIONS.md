# 운영

시간: 연구 예약은 Asia/Seoul, DB 기록은 UTC. 무료 cron은 1분 단위 기동이며 정확한 초 단위를 보장하지 않는다.

논문 등록 → 분기점 공개 입력·기준 분리 → 저장 → 세 체크 승인 → 새 계획(초기 일시정지) → 시작. 승인 내용이나 확정 모델·프로토콜은 수정하지 않고 새 revision/plan을 만든다.

수동 웹 경로는 새 채팅마다 해당 단계의 전체 프롬프트와 schema를 전달한다. PDF는 실제 저장된 승인 공개본만 첨부한다. 화면에 표시된 모델·모드·실행 시각·도구·검색·메모리를 기록하되 확인하지 못한 값은 null이다. 응답 원문은 파싱 전에 보존된다. 사람이 정정한 JSON은 원문과 별도 저장하고 기본 주 분석에서 제외한다.

API: 기본 OFF, 예산 $0. 관리자 허용·조직 잔량 확인·단계별 capability PASS·가격·요청 비용 예약이 모두 필요하다. 전송 시작 뒤 응답 보존 전 중단된 요청은 unknown_remote로 둔다. 제공사 기록을 확인한 사람이 명시적으로 미처리를 확인하기 전까지 자동 재전송하지 않는다. 저장 원문은 재파싱하며 모델을 다시 호출하지 않는다. pause/cancel은 새 claim을 막으며 이미 전송한 요청을 취소했다고 주장하지 않는다.

PDF·업로드·Excel·ZIP·백업 작업 중에는 해당 탭을 유지한다. DB 대기열의 실험 실행과 브라우저의 파일 작업은 별도다. PDF의 기술적 제거 검수는 수학적 내용 누출이 없다는 보증이 아니므로 팀이 승인해야 한다.

자료 승인·본실험 종료·데이터 확정 후 전체 백업의 manifest와 모든 ZIP 파트를 내려받는다. 실제 저장 확인 후에만 완료를 기록한다. 최근 3개를 독립 위치에 보관한다. 계정 인증/OAuth·provider key·master key는 포함되지 않는다. 관리자의 별도 보안 보관 대상이다.

복원은 모든 hash를 먼저 검수하고 새 비활성 공간에 UUID를 재매핑한다. 계획은 paused, API/scheduler OFF, 비밀은 미복원이다. 원본·공개본·raw·후보·평가·지표를 대조한 뒤 활성화한다. 기존 활성 공간을 덮어쓰거나 공간 확보를 위해 먼저 삭제하지 않는다.
